# movie hunter user stories

all five stories are part of the mvp. they should work on a phone or laptop.

## 1. search for a movie

I want to type a movie title on the home page and see what comes up.

while I wait, I can tell the search is still running. if nothing matches, I can change the title right there. if the search fails, I can try again with the title I already typed.

## 2. pick the right movie

if a friend recommends the 1984 version of *dune*, I want to tell it apart from the 2021 version.

each result shows the title and year, plus a poster and short description if they’re available. I can save the version I want right from the results, even if the poster is missing.

## 3. keep my watchlist private

I want my own account so I can come back to my list later.

I can create an account and sign in. only I can see my list, change it, or remove movies from it.

## 4. save a movie for later

when I find something I want to watch, I want to save it before I forget the title.

when I click save, I can see that the movie was added. if I click twice, it only shows up once. if I sign out and come back, the version I picked is still there.

## 5. update my watchlist

after I watch a movie, I want to mark it as watched. if I lose interest in one, I want to take it off my list.

when I refresh the page, the movie is still marked as watched. if someone else saved the same movie, removing it from my list leaves it on theirs.
